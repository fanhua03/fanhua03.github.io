FlashMLA deepseek-ai/FlashMLA CUDAMLAkernelKV cache
DeepSeek 的 MLA 注意力算子库：384 个线程、3 个 warpgroup 把分页量化 KV 的 decode 跑满。
  • MMA 的 M 维固定 64 个头、N 维 64 个 top-k token；384 个线程里 128 个算 exp、128 个反量化、1 个发 tcgen05 MMA、1 个搬原始行、1 个算 TMA 坐标。

DeepSeek 的轻量数据框架：逻辑计划 → 分区任务组 → 3FS 上的文件队列 → 每 task 一个 DuckDB 连接，全程无长驻服务。
