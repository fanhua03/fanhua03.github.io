deepseek-recipe 架构图｜三种接口，翻成一种对话

把 OpenAI、Anthropic 那几种不一样的接口，先翻成一套统一的对话，再变成模型吃的 prompt；模型吐出来的，再翻回去。

人话版大模型服务有好几种接口格式，OpenAI 一种、Anthropic 一种，长得都不一样。这个库把任何格式的请求先翻成一套统一的对话结构，再变成模型真正吃的 prompt 和 token；模型吐出来的东西，再翻回原来那种格式。它不负责跑模型，也不负责发网络请求，那些由调用它的服务来做。

仓库 deepseek-ai/deepseek-recipe 语言 Rust / Python 规模 22,340 行 出处 8 处能对到源码 更新 2026-11-04

三个反直觉的地方

  • 三种接口进来先翻成一套统一的对话结构，后面就不用再管原来是哪种格式。
  • 变成 prompt 时顺手记下特殊标记在字符串里的位置，编码时不用再找一遍。
  • 模型边吐边翻：每来一小段就解析成事件，再包成对应格式推给客户端。
