DeepSeek-OCR 架构图｜整页文档压成 273 个视觉 token

动态切块 → SAM+CLIP 编码并做 16× 下采样 → 273 个视觉槽位 → MoE 解码器输出带坐标的 Markdown。

仓库 deepseek-ai/DeepSeek-OCR 语言 Python 规模 3,198 行 证据 7 处 file:line 更新 2026-11-04

三个反直觉的地方

  • 16× 压缩发生在编码器内部：SAM 的 16 像素 patch 把 1024² 变 64×64=4096 个位置，neck 后两次 stride-2 卷积压到 16×16=256 个 token。
  • 一页的视觉开销固定是 273 个槽位：16×16 网格每行补 1 个 newline、末尾补 1 个 view_separator，即 16×17+1。
  • token 数只跟像素档位走、不跟字数走：512→64、640→100、1024→256、1280→400；版面坐标靠 <|ref|>…<|det|>[x1,y1,x2,y2] 从文本里还原。
