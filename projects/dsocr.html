DeepSeek-OCR 架构图｜整页文档压成 273 个视觉 token

把一整页文档「看」成几百个小方块，再翻成文字，还告诉你每行字在哪。

人话版DeepSeek-OCR 干两件事：先把一整页图压成几百个「视觉小块」，再把这些小块翻成文字，顺便告诉你每行字在页面上的位置。

仓库 deepseek-ai/DeepSeek-OCR 语言 Python 规模 3,198 行 出处 7 处能对到源码 更新 2026-11-04

三个反直觉的地方

  • 压缩发生在编码器里：一张 1024×1024 的图先切成 16 像素的小块，再两次减半，最后只剩 16×16=256 个 token。
  • 一页的「视觉开销」是固定的 273 个：16×16 的格子每行补一个换行、末尾补一个分隔符，正好 16×17+1。
  • 花多少 token 只看图片多大，不看字有多少：512 像素→64 个，1024→256 个，1280→400 个；位置则靠输出里的坐标标记还原。
