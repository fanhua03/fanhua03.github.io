DeepJIT 架构图｜源码进来，机器码出去

同一段 kernel 源码，第一次用时现场编译并存起来，之后直接读出来跑——换卡、换参数都不用重装。

人话版显卡上跑的代码，一般要提前编好、跟着安装包一起发出去。这个项目改成「用到的时候再编」：第一次遇到某段代码，现场调编译器编成机器码并存到硬盘；下次遇到一模一样的代码，直接读出来用。好处是换显卡、换编译参数都不用重新打包，代价是第一次要等编译器干活。

仓库 deepseek-ai/DeepJIT 语言 C++ / Python 规模 10,658 行 出处 8 处能对到源码 更新 2026-11-04

三个反直觉的地方

  • 编过的东西按「源码 + 编译器版本 + 编译选项」算一个指纹，指纹一样就直接拿旧的。
  • 两级缓存：先看进程内存里的表，再看硬盘上的目录；硬盘上先写 .committed 再改名，别人要么看不见、要么看见完整的。
  • 第一次要现场调 nvcc，之后同机同选项都不用再编；编完还会检查有没有寄存器溢出。
