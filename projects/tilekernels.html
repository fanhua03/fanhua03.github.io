TileKernels 架构图｜按块写代码，编译器翻译成线程

把「按块搬数据、按块算」写成一种方言，再由编译器翻译成显卡指令——同一份写法能跑 NVIDIA 和昇腾。

人话版显卡干活前，得有人把活儿切成一块一块、分给几千个线程，还得管好每块数据放在哪个片上内存。这个项目用一种「按块描述」的写法来做这件事：你只说这块数据怎么搬、怎么算，翻译成显卡指令的活交给编译器。好处是同一份写法能换后端跑，代价是得按它的规矩写。

仓库 deepseek-ai/TileKernels 语言 Python / TileLang 规模 26,181 行 出处 8 处能对到源码 更新 2026-11-04

三个反直觉的地方

  • 你只写开多少 block、每个 block 多少线程，搬运和计算都按块写（T.Kernel / T.copy / T.Parallel）。
  • 块多大、用几个线程是算出来的：小 batch 用 64 线程 × 32 元素，block_k 取与 hidden 的最大公约数。
  • 同一份写法换后端就能跑：探测到昇腾就换另一份 launcher，形状用 T.dynamic 留给运行时决定。
