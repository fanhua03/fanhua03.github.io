jq 架构图｜把过滤器编译成一台会倒退的虚拟机

一个命令行小工具：你给它一条规则，它把 JSON 变成你要的样子。

人话版jq 是命令行里处理 JSON 的小工具。奇怪的是你给它一条规则，它可能一次吐出好几个结果——因为它会「存档读档」：算出一个就先记下算到哪了，下次从记下的地方接着算。

仓库 jqlang/jq 语言 C 规模 28,460 行 出处 7 处能对到源码 更新 2026-11-04

三个反直觉的地方

  • 一条规则能吐出好几个结果（比如 .[]），靠的是「存档」：算出一个结果就先记住算到哪了，下次从那儿接着算，不用重头来。
  • 它自带的那批函数（map、select 这些）不是 C 写的，就是用 jq 自己的语言写的源码，编译时和你的程序拼在一起——所以得先「对上名字」再「翻译成机器指令」。
  • 整个仓库最长的文件不是执行引擎，是一个专门把小数打印得和输入一模一样的库（4276 行）。就为了让 1e1000 原样输出，不要变成 inf。
