FlashMLA 架构图｜一个 CTA 吃完 2048 个 top-k

给显卡写的专用程序：算「注意力」这一步，一次吃完 2048 个候选。

人话版FlashMLA 是一段专门给显卡写的计算程序，只干一件事：算注意力。它把一个 GPU 核心的活拆给 384 个线程，各管一段，最后拼起来。

仓库 deepseek-ai/FlashMLA 语言 CUDA C++ / Python 规模 19,093 行 出处 8 处能对到源码 更新 2026-11-04

三个反直觉的地方

  • 一个 GPU 核心里 384 个线程分工：128 个算指数、128 个把压缩过的数据还原、1 个发矩阵指令、1 个搬数据、1 个算地址——像流水线，各干一段。
  • 数据是压缩着存的，用的时候才现算「第几页第几个」把它捞出来：一次搬 4 行，64 行分 16 次搬完；索引越界就填 -1，让硬件自己跳过。
  • 压缩得很狠：512 个数字压成 8 位整数，连位置编码一起压，再配 16 字节缩放系数。一个 token 只占 528 字节；更狠的版本只占 256 字节。
