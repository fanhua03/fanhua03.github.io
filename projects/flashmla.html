FlashMLA 架构图｜一个 CTA 吃完 2048 个 top-k

DeepSeek 的 MLA 注意力算子库：384 个线程、3 个 warpgroup 把分页量化 KV 的 decode 跑满。

仓库 deepseek-ai/FlashMLA 语言 CUDA C++ / Python 规模 19,093 行 证据 8 处 file:line 更新 2026-11-04

三个反直觉的地方

  • MMA 的 M 维固定 64 个头、N 维 64 个 top-k token；384 个线程里 128 个算 exp、128 个反量化、1 个发 tcgen05 MMA、1 个搬原始行、1 个算 TMA 坐标。
  • 分页 KV 的块号和块内偏移在 kernel 里现算，拼成 TMA 坐标后每次 gather4 搬 4 行，64 个 token 用 16 次发完；非法索引填 -1 让 TMA 自己跳过。
  • 每 token 只占 528 B：512 维全部量化成 fp8 e4m3（连 64 维 RoPE 一起，没有 bf16 尾巴）+ 16 字节 ue8m0 scale（每 32 维一个）；fp4 版是 256 B。
