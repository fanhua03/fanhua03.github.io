smallpond 架构图｜DuckDB 切片，3FS 上跑任务

DeepSeek 的轻量数据框架：逻辑计划 → 分区任务组 → 3FS 上的文件队列 → 每 task 一个 DuckDB 连接，全程无长驻服务。

仓库 deepseek-ai/smallpond 语言 Python 规模 15,996 行 证据 8 处 file:line 更新 2026-11-04

三个反直觉的地方

  • Planner 把作业切成 producer/consumer 任务组：producer 数 = min(max, 2×executor×ceil(cpu/cpu_limit))，consumer 只合并同分区，不搬数据。
  • 没有常驻服务：driver 只有 ray/scheduler/executor 三种模式，队列就是 data_root 下 enqueued/ 里的 zstd+pickle 文件，pop 靠 rename。
  • DuckDB 是每个 task 私有的 :memory: 连接：输入建成 read_parquet 视图，输出 COPY ... (FORMAT PARQUET, ZSTD, PER_THREAD_OUTPUT)。
